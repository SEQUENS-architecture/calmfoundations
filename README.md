# Calm Foundations

One-page website for one-to-one tuition, social and emotional learning and PSHE, therapeutic art, school consultancy, and parent advice for SEN and behaviour.

## Files
- `index.html`: the whole site (styles and script included). No build step.
- `robots.txt`, `vercel.json`: ready for hosting.

## Still to set up
- The email address hello@calmfoundations.org (create it or a forwarder in 123 Reg, under Email)
- Prices, if wanted on the site (the FAQ currently says to get in touch)

## Brand
`brand/` holds the logo: `mark.svg` (the stones), `logo-full.png` (stones and name, transparent), `logo-full-on-dark.png`, and `icon-square.png` (for WhatsApp or social profile pictures).

## Contact form
The form does not send anything yet. Connect a form service (for example Formspree) by setting the form's `action`, or keep the current message that asks people to email.

## Check
The art service is described as "Art and mindfulness" and says it is wellbeing support, not therapy. "Art therapist" is a protected title in the UK (HCPC registration).

## Deploy (Vercel)
1. Create a GitHub repository and upload these files to `main`.
2. In Vercel: Add New Project, import the repository, Deploy. No settings needed.
